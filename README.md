# 스마트 카운터 v1.1 — 반복 제품 수량 세기

아이폰 Safari / 아이폰 홈 화면 웹앱(PWA) / PC 브라우저에서 실행하는 오프라인 물체 수량 분석 도구입니다.
정렬 간격을 가정하지 않고, 사진에서 **물체의 실제 영역을 검출해 위치마다 빨간 점**을 표시하고 **총 개수를 사진 하단에 큰 글씨**로 표시합니다.

**중요:** 임의의 복잡한 장면에서 모든 제품을 정확하게 인식하는 범용 AI 모델이 아닙니다. 색상·형태·크기에 기반한 **브라우저 내부 이미지 분할 + 반복 후보 비교** 방식입니다. 개수는 반드시 사용자가 확인하세요. 의료용 알약 조제/복용 검수 등에 단독으로 이용하지 마세요.

## 주요 변경 (v1.0 → v1.1)

- 물체별 순번 숫자, 큰 원형 검출 테두리 제거 → **개별 물체 중심에 빨간 점만 표시** (흰 외곽선은 시인성용)
- 카메라 미리보기·사진 화면 **하단에 큰 총수량 오버레이**, 저장한 PNG에도 같은 표시
- `반복 제품 구분` 설정: **자동 분류 / 전체 검출 / 기준 물체와 유사한 물체만**
- 사진에서 `기준 물체 선택` 후 제품 하나를 누르면 **면적·회전 불변 형태 비율·평균 색상**을 이용해 유사한 후보를 선택
- 둥근 물체뿐 아니라 **캡슐, 사각형, 비정형 물체**에 대한 반복 후보 그룹 비교
- 기본 검출 분리 과정에서 긴 캡슐 하나를 여러 개로 잘못 자르는 경우를 억제
- 수동 추가/제외, 배경색 지정, 감지 영역 제한, 라이브 분석, 재분석, 결과 공유, PWA/오프라인 기능 유지

## 아이폰 실행·업데이트 방법

1. 다운로드한 ZIP 압축을 풉니다.
2. GitHub의 기존 `smart-counter` 저장소에서 **같은 이름의 파일을 모두 덮어쓰기**합니다. `icons/` 폴더도 유지하세요.
3. GitHub Pages가 활성화되어 있다면 기존 사이트 주소를 그대로 사용할 수 있습니다.
4. 배포 완료 후 아이폰 Safari 또는 홈 화면 웹앱을 **완전히 종료하고 다시 열거나 새로고침**하세요. 홈 화면에 다시 추가할 필요는 보통 없습니다.
5. 처음 설치한다면 GitHub 공개 저장소의 `Settings → Pages → Deploy from a branch → main / (root)` 설정 후 게시된 `https://사용자명.github.io/저장소명/` 주소로 접속합니다.
6. 카메라는 HTTPS URL 또는 로컬 테스트 환경(https, localhost)에서 사용 가능합니다. iPhone Safari에서는 카메라 사용 권한을 허용하세요.

## 실시간 인식

- `실시간 인식 → 카메라 켜기`를 누릅니다.
- 평평한 바닥에 놓인 같은 종류의 제품을 수직 방향으로 비춥니다. 일정한 간격으로 정렬할 필요는 없습니다.
- 약 0.6초 간격으로 화면을 캡처해 분석합니다(기기 성능·프레임 처리 상황에 따라 실제 속도는 달라집니다).
- 빨간 점 하나가 **검출된 한 개**이며, 사진 화면 아래쪽에 큰 총수량을 보여줍니다.
- `촬영 · 정밀 분석`을 누르면 고화질 캡처로 다시 검출하며, 수동 검증을 할 수 있습니다.

## 촬영 후 정밀 분석

1. 카메라 촬영 또는 `사진 불러오기`를 사용합니다. 이미지는 최대 약 200만 화소로 줄여 분석합니다.
2. 처음에는 **반복 제품 자동 분류** 모드로 비슷한 후보를 묶어 셉니다.
3. 배경 잡음이나 다른 물체를 함께 셀 때는 **기준 물체 선택** 버튼을 누릅니다. 화면이 사진으로 이동하면 **원하는 종류의 제품 한 개를 터치**합니다.
4. 기준 물체를 선택하면 크기, 형태, 색상이 비슷한 검출 후보만 다시 셉니다. 제품이 너무 다양하거나 원근 차이가 클 경우 `반복 제품 유사도 허용 범위`를 조절해 다시 분석합니다.
5. 검출 대상이 하나 또는 두 개뿐이라 자동 분류가 애매하다면 `전체 검출`이나 `기준 물체 선택`을 사용하세요.
6. 잘못 센 물체의 **빨간 점을 터치하면 제외**, 빈 곳의 **물체 중심을 터치하면 1개 추가**, 제외한 위치의 회색 X를 다시 터치하면 복구됩니다.
7. `영역 지정`을 누르고 사진 위를 드래그하면 그 영역만 셉니다. `배경 찍기`는 비어 있는 바닥을 터치하여 색상 기준을 바꿉니다.
8. `결과 저장`을 누르면 검출 물체의 빨간 점과 맨 아래 최종 수량이 들어간 PNG 파일이 공유 또는 다운로드됩니다.

**설정을 변경해 다시 분석하면 수동 보정(+/-)은 초기화**됩니다. 저장할 사진은 수동으로 확인한 뒤 `결과 저장`을 사용하세요.

## 검출 개선을 위한 촬영 팁

- **물체 간 간격이 일정할 필요는 없습니다.** 대신 다른 물체에 가려지지 않도록 가능하면 한 층으로 펼쳐 놓으세요.
- 배경은 대상 제품과 대비되는 무광 단색을 사용합니다.
- 카메라를 바닥에 최대한 수직으로 두고, 조명이 균일하도록 그림자와 난반사를 줄이세요.
- 여러 종류의 제품이 섞여 있으면 기준 물체 선택으로 대상 제품의 검출 후보를 좁히세요.
- 제품이 작아 누락되면 `최소 물체 크기`를 낮추고 민감도도 조절하세요. 잘못 인식된 먼지가 늘면 반대로 조절하세요.
- 접촉한 물체는 `붙은 물체 분리 시도`로 중심점 추정을 합니다. **겹쳐 보이지 않거나 서로 붙어 한 덩어리가 된 제품을 완벽하게 분리할 수는 없습니다.**
- 마커가 없는 곳이 반드시 물체가 없는 것은 아닙니다. 검출 과정에서 누락될 수 있으므로 화면 전체를 확인하세요.

## 개발 구조

- `index.html` — 화면과 UI
- `app.css` — 반응형 디자인, 빨간 점·총수량 표시
- `app.js` — 카메라, 사진 업로드, 기준 물체 선택, 편집, 저장
- `detector.worker.js` — 배경 분리, 연결 요소, 접촉 물체 분할, 유사 형태/색상 후보 분류
- `sw.js` — 네트워크 우선 캐시, 오프라인 복구
- `manifest.webmanifest`, `icons/` — 홈 화면 등록 메타데이터 및 아이콘

서버, 로그인, Firebase, OpenCV CDN, 별도 API 키는 필요 없습니다. **사진 데이터는 서버로 전송하지 않습니다.**

## 개발 환경 테스트 (합성 이미지)

| 테스트 | 목표 수량 | 검출 |
|---|---:|---:|
| 개별 검은 원형 물체 | 15 | 15 |
| 개별 흰 원형 물체 | 24 | 24 |
| 맞닿은 원형 물체 | 10 | 10 (추정 분리 포함) |
| 긴 캡슐형 물체 | 12 | 12 |
| 사각 물체 | 12 | 12 |
| 작은 원형 물체 | 210 | 210 |
| 불규칙 배치 원형 28개 + 다른 조각 7개 | 28 | 28 |
| 방향이 다른 캡슐 18개 + 사각형 6개 | 18 | 18 |
| 불규칙 배치 작은 원형 물체 | 40 | 40 |

브라우저 화면 테스트에서 사진 업로드, 자동 18개/전체 24개/기준 선택 18개 전환, 빨간 점 수동 제외 및 복구, 결과 PNG 저장을 확인했습니다.

**이는 테스트 목적으로 만든 합성 이미지 결과일 뿐 정확도 통계나 실물 검증 결과가 아닙니다.** 실제 아이폰 하드웨어와 다양한 실물 제품은 별도 촬영 검증이 필요합니다.

## 한계 및 다음 개발 단계

복잡한 무늬의 물체, 투명한 물체, 여러 색상으로 구성된 포장 제품, 복잡한 바닥, 서로 완전히 겹친 제품 등에는 세그멘테이션만으로 정확도가 부족할 수 있습니다. 이런 유형에 대해서는 제품별 실물 사진을 충분히 모아 **인스턴스 세그멘테이션 학습 모델**을 추가해야 합니다. 단순히 감도를 높이는 것으로 해결되지는 않습니다.

카메라의 화면 꺼짐/백그라운드 분석은 iOS 브라우저 제약으로 지원하지 않습니다. 상시 서버 운영이나 계정 공유 기능은 현재 포함되지 않았습니다.
